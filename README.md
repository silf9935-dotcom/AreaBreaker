# AreaBreaker 1.0.1

Клиентский Fabric-мод для Minecraft Java 1.21.11. Основной сценарий — одиночный мир.

## Управление

- **V** — открыть меню AreaBreaker.
- Выбери размер области: 1×1 (выкл.), 2×2, 3×3, 4×4, 5×5 или 10×10.
- Режим **Область** ломает блоки в выбранной плоскости.
- Режим **Жила** ищет соприкасающиеся блоки того же типа (лимит 64 блока, радиус 6).
- Формы: квадрат, стена, полоса и туннель.
- Защита инструмента останавливает дополнительную добычу до полного износа кирки.
- Автоподбор переносит выпавшие предметы в инвентарь, если там есть место.

Настройки применяются сразу. Мод рассчитан на одиночную игру и не обеспечивает серверную синхронизацию настроек в мультиплеере.

## Книги шахтёра

Все книги — настоящие зачарованные книги Minecraft, их можно применить к совместимым инструментам через наковальню.

| Книга | Зачарования |
|---|---|
| Шахтёр I | Эффективность II, Удача I, Прочность II |
| Шахтёр II | Эффективность III, Удача II, Прочность III |
| Шахтёр III | Эффективность V, Удача III, Прочность III, Починка I |

### Рецепты

**Шахтёр I**
```
[   ][Жел][   ]
[Лаз][Кам][Лаз]
[   ][Жел][   ]
```
Жел — железный слиток, Кам — камень, Лаз — лазурит.

**Шахтёр II**
```
[Зол][   ][Зол]
[Лаз][Кни][Лаз]
[Зол][   ][Зол]
```
Зол — золотой слиток, Лаз — лазурит, Кни — книга.

**Шахтёр III**
```
[Алм][Изм][Алм]
[Аме][Кни][Аме]
[Алм][Изм][Алм]
```
Алм — алмаз, Изм — изумруд, Аме — осколок аметиста, Кни — книга.

Если рецепт ещё не открылся в книге рецептов, попробуй получить один из ингредиентов или выдать рецепт командой:
`/recipe give @s areabreaker:miner_i`, `miner_ii` или `miner_iii`.

## Установка

1. Установи Minecraft Java 1.21.11, Fabric Loader и Fabric API.
2. Положи JAR AreaBreaker в папку `mods`.
3. Запусти игру на Java 21 или новее.

## Сборка из исходников

Требуется Java 21. Выполни `./gradlew build`; JAR появится в `build/libs/`.
