# AreaBreaker

Fabric client-side mod for Minecraft 1.21.11. Designed for single-player worlds.

Press **V** to choose an area size (2x2, 3x3, 4x4, 5x5, or 10x10). Hold the attack key while aiming at a block to mine the selected area sequentially.

## Build

Use Java 21 and run `./gradlew build` (or `gradle build`). The output JAR is in `build/libs/`.
